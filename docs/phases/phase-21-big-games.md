# Phase 21+: Large games

[← Master plan](../PLAN.md) · Milestone M7 · **Status: ⏳ Not started** · Effort: **high per game**

Design reference: [multi-game proposal](../proposals/multi-game-platform.md), section 2 (step G).

## Goals

- Add large games one at a time, each as its own phase (21, 22, …), the way Phases 7–8 covered Sky Team's base box and expansion.

## Candidates

| Game | What it adds to the platform |
| --- | --- |
| Pandemic | 2–4 co-op seats; event cards played out of turn (`prompt` actors); hidden deck order |
| Isle of Skye | 2–5 seats; simultaneous secret pricing; bag draws; scoring |
| Twilight Struggle | 2–3 hour games (save and resume, maybe async play with notifications); hidden hands; many prompts to the opponent |

**Licensing:** these are published, trademarked games. Fine for a private, invite-only site for friends; a public site needs the publishers' permission or original games (see [Phase 12](phase-12-deploy.md)).

## When a game starts

Split this file: create `phase-NN-<game>.md` with goals, scope, tasks, checklist and a "Done when", like every other phase. The rulebook is the spec; rule questions go into that file's Open questions, marked "Assumption (to confirm)".
